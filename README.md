# How to set up the keyboards: #

## Android ##

1. Please download the .apk file located in the Android/Releases directory

2. Enable the keyboard in your phone's keyboard settings

3. If possible on your model, set it as the default pop-up keyboard.
   
   If not, long-press the language selection icon, then select it from the list.

## Linux ##

1. Make sure you have IBus installed and configured.
  
2. Please download the .mim file in the Linux directory.
   
3. Put it in the .m17n.d directory and restart IBus.

## MacOS ##

1. Please download SituRgyalrong.bundle into your ~/Library/Keyboard Layouts directory.

2. In Input Sources find SituRgyalrong in the "Other" category.

3. Add the layout.

## Windows ##

1. Please download and unzip the provided .zip folder in the Windows directory

2. Run the setup.exe file.

3. Restart the system, and add the layout in settings.
